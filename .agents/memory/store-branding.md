---
name: Store branding and editability
description: Project rule for fixed branding and reusable wholesale-store data.
---

The fixed brand wordmark is exactly “JHARKHAND ENTERPRISES”. Store-specific records such as companies, products, customers, suppliers, sales, and purchases should remain editable so the dashboard can be reused for another store.

**Why:** the user explicitly distinguished the fixed logo from editable store data.

**How to apply:** preserve the exact wordmark when changing the interface; do not hard-code catalogs or transaction data as uneditable business configuration.
